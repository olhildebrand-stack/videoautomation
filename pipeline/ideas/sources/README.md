# Source material

What the operator feeds in: swipe files, transcripts of reels that worked,
notes on what a niche responds to, screenshots of posts, anything.

Drop it here in whatever shape it arrives. Nothing here is read automatically
and nothing has a required format.

**What matters is what happens to it.** Material read once and left here is
material that gets re-read from scratch every session. When something in here
turns out to be true more than once, write it as a rule in `../IDEAS.md` under
*Learned rules* and say which file it came from. The folder is the evidence;
`IDEAS.md` is what was learned from it.
