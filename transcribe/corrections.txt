# Matching is case-SENSITIVE and whole-word, so "Cloud => Claude" rewrites the
# proper noun without touching a legitimate lowercase "cloud". Every applied
# correction is recorded in the JSON under "corrections_applied", so you can
# always see what was changed.
#
# Use this for terms hotword biasing keeps getting wrong. Prefer adding to
# vocabulary.txt first -- that steers the model. This overrides it outright.

# Whisper hears the assistant's name as the English word "cloud", in lower
# case, mid-sentence: "skicka den till cloud direkt". The lowercase rule below
# is therefore the one that does the work.
#
# TRADE-OFF: this also rewrites a genuine lowercase "cloud" (as in cloud
# computing). In Swedish speech that sense is usually "molnet", so the risk is
# low -- but if you ever discuss cloud infrastructure in English loanwords,
# delete the lowercase rule and fix those occurrences by hand.

Cloud => Claude

clouden => Claude
